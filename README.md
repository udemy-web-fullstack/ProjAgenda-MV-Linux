# 📔 Projeto Agenda 2026

Este é um projeto de agenda desenvolvido durante o curso de JavaScript e TypeScript do Luiz Otávio Miranda.

## 🚀 Status: Concluído e Hospedado!
O projeto foi migrado com sucesso da Google Cloud para a **DigitalOcean** e está totalmente funcional.

### 🛠 Tecnologias Utilizadas:
* **Backend:** Node.js, Express
* **Banco de Dados:** MongoDB (NoSQL) com Mongoose
* **Servidor Web:** Nginx (Proxy Reverso)
* **Gerenciador de Processos:** PM2
* **Segurança:** SSL/HTTPS via Certbot
